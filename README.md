#  Hotel Operations Analysis

##  Overview

This project performs End-to-End Exploratory Data Analysis (EDA) on hotel booking data to uncover trends in bookings, cancellations, customer behavior, revenue generation, and operational efficiency.

---

##  Objectives

- Analyze hotel booking trends
- Understand customer behavior
- Identify cancellation patterns
- Improve occupancy insights
- Support operational decision-making

---

##  Analysis Performed

- Data Cleaning
- Missing Value Treatment
- Duplicate Removal
- Feature Engineering
- Univariate Analysis
- Bivariate Analysis
- Correlation Analysis
- Outlier Detection

---

##  Visualizations

- Booking Distribution
- Monthly Reservations
- Lead Time Analysis
- ADR Distribution
- Customer Type Analysis
- Cancellation Trends
- Country-wise Bookings
- Market Segment Analysis
- Correlation Heatmap

##  Business Insights

- Peak booking months identified.
- Cancellation rates analyzed across customer segments.
- Online Travel Agencies contributed the highest bookings.
- Longer lead times showed higher cancellation probability.
- Repeat customers exhibited lower cancellation rates.
